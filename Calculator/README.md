# Smart Calculator (C# Console App)

## 📌 Overview
**Smart Calculator** is a C# console application built to strengthen core programming logic and confidence.  
The application uses a menu-driven interface that allows users to perform basic arithmetic operations safely and repeatedly until they choose to exit.

This project focuses on writing clean control flow, handling user input correctly, and structuring code using methods.

---

## 🎯 Goal
- Build confidence with core C# logic
- Practice writing structured, readable console applications
- Reinforce control flow and input validation concepts

---

## ✨ Features
- Menu-driven calculator interface
- Supports:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Safe handling of invalid input
- Prevents division by zero
- Runs in a loop until the user chooses to exit

---

## 🧠 Concepts Practiced
- `switch` statements
- Methods
- Loops (`while`)
- Input validation
- Basic error handling
