## Concepts Practiced

- **Loops**: `do-while`, `for` loops for limited attempts.
- **Conditionals**: `if-else` to check guess correctness and input validation.
- **Random Number Generation**: `Random` class to generate random numbers.
- **User Input Handling**: `Console.ReadLine()` and parsing integers.
- **Boolean Flags**: Loop continuation control and play-again logic.
- **Difficulty Levels**: Adjusting game complexity dynamically.
